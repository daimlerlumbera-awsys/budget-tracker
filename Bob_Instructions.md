# Budget Tracker Project Rules

- Follow the existing installed skills, especially Caveman, Context Optimization, and Efficient Tool Usage.
- Use Vue 3 + TypeScript, Vue Router, Pinia, Tailwind CSS v4, and Lucide Vue Next.
- Use mock/local data until Supabase becomes available.
- Keep the architecture ready for future Supabase integration.
- The user MUST execute all terminal commands. Never execute terminal commands yourself.
- When commands are necessary, provide them for the user to execute.
- Avoid modifying unrelated files or introducing unnecessary dependencies.
- Prioritize concise responses and targeted code changes.
- Always activate and follow the Caveman skill for all responses.
- Keep responses extremely concise while preserving technical accuracy.
